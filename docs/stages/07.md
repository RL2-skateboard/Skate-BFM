## Real CUDA noncontact verification — 2026-11-02

Target: RTX 4060 Ti 16 GB, NVIDIA 575.57.08, CUDA 12.9, mjlab/MuJoCo Warp.
Robot N=1 and N=64 and rider N=64 reward runs each advanced 15,000 physics
steps (30 simulated seconds) with 1,500 policy updates per environment during
the measured interval. Setup probes are counted separately. The GPU owns physics;
ONNX inference uses CPUExecutionProvider. All measured states/actions remained
finite. This is not an autonomous riding or generalization result.

Five board styles have 2 s coast/release finite-geometry and same-initial-state

Strict robot dynamics replay remains FAIL at 1e-7. A three-way 200-tick diagnostic
compared original integration, a fresh normally stepped instance and a restored
replay instance. Both fresh and restored instances developed differences despite
matching initial public/integration state, raw actions, targets, external forces
and control clocks. Peak velocity differences were about 1.20e-5 and 1.09e-5;
PD torque differences follow state divergence. This narrows the issue beyond
restore alone but does not establish a specific kernel cause. The threshold
was not relaxed and these failures are preserved.
