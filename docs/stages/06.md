## Noncontact engineering verification — 2026-11-02

The shared automatic check `validation/noncontact06.py` now covers all three
presets with ten resets, state roundtrip, a world/body-frame force at an explicit
point, exact step-duration expiry, clearing, and real policy/F/reset dynamics
replay. Checkpoint absence is BLOCKED, not a silently skipped policy pass.

The native and GPU wrappers accept selected environment IDs; native accepts only
its single environment. State writes validate complete shapes, finite values
and root quaternions before mutation. External force state is independent for
each selected body/environment. The scene remains free-base except the explicit
robot-only joint inspection fixture.

Engineering guards are explicit constructor parameters: episode_time_limit=30 s,
out_of_bounds_distance=5 m, offboard_distance=1 m; each may be disabled with None.
These are runtime diagnostics, not calibrated task-success thresholds. Both
pelvis and deck movement are checked against episode origins. The separate
preset is not considered offboard merely because it starts beside the board;
offboard latches only after approaching the board or in an on-board preset.
Terminated and time-limit truncated are independent, and no failure is hidden
by an automatic reset.

Version-2 recordings preserve initial integration/control state and per-physics
tick commands, events and applied force. Native bench/board/robot none/pose/policy
replay checks and a rider policy force/reset check measured zero state error at
the registered 1e-7 short-horizon threshold. The 100-tick records cover 0.20 s,
with a reset at tick 50: their longest continuous interval is 0.10 s, not 1 s.
Snapshots are used for comparison only after the initial restoration.
