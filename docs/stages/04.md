# Stage 04

Status: WAITING_REVIEW. Stage 03 user acceptance is recorded; Isaac Sim remains
excluded from delivery.

Implemented native MuJoCo contact bench using the actual procedural standard
skateboard from Stage 02, including deck, front/rear trucks and four wheels:

- a real free foot body with mass, freejoint and finite box collision;
- a fixed real skateboard for `pull`, `twist`, and `unload`;
- a free real skateboard for `freeboard`;
- runtime contact normal/tangent force, point-relative slip speed, contact
  count and friction power diagnostics;
- shared contact XML and runtime metrics in `physics/contact.py`.

Run the visual experiments:

```bash
python play.py --backend mujoco --scene contact --experiment pull --record runs/04_pull
python play.py --backend mujoco --scene contact --experiment twist --record runs/04_twist
python play.py --backend mujoco --scene contact --experiment unload --record runs/04_unload
python play.py --backend mujoco --scene contact --experiment freeboard --record runs/04_freeboard
```

Contact controls: `A/D` changes tangential pull force, `T/Y` changes twist
torque, `Space` pauses, `N/M` step, `R` resets and `E` releases the external
load. The UI label identifies the external fixture by experiment name. A/D/T/Y
are input clamps for the native baseline, not learned contact forces.

Use the four recorded experiments and inspect their JSONL diagnostics. They
are a native physical baseline and do not claim real-material accuracy. No
automatic check implementation is shipped; fit/evaluate are not active until
an audited dataset and `configs/contact.yaml` are supplied.

The real-board contact windows now start and record successfully. Stage 04
