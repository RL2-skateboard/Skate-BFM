# Procedural assets

Board and gallery geometry is generated locally by skate-sim, revision 1.
No third-party meshes are embedded. Units: metres, kilograms, seconds, radians.
Collision proxies are boxes and cylinders; the ramp is a convex triangular prism.
Masses are design assumptions. build/play/check use the same BoardStyle objects
and SHA-256 configuration hash. Generated XML is output, not a parameter source.

Robot source planned for review: https://github.com/LeCAR-Lab/BFM-Zero and
https://huggingface.co/LeCAR-Lab/BFM-Zero . No robot or checkpoint is included yet;
version and license verification remains pending before robot asset selection.
